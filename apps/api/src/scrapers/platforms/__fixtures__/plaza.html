Esta casa encantadora oferece o equilíbrio perfeito entre conforto e elegância. Com 3 quartos espaçosos, incluindo 2 suítes privativas, é ideal para famílias ou quem busca espaço extra. Os 4 banheiros, todos com acabamentos modernos, garantem praticidade para todos os moradores.
